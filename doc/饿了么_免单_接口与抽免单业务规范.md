# 饿了么「免单」接口与抽免单业务规范

> **业务定位**: 饿了么外卖三端抽免单、限时抽、爆红包发放与免单卡权益  
> **抓包日志来源**: `scratch/tb.log`  
> **核心插件 ID**: `pluginId = 2021006118622831` (三端抽免单插件)  
> **承载业务场景**: `TIME_LIMIT_DRAW_NEW` / `ET_RIGHTS_CENTER` / `ENGAGE_HUB`

## 一、免单模块核心接口定义

### 1.1 限时抽免单咨询与抽奖接口 (`timelimitdraw.consultunit`)

该接口在用户进入免单活动页时被触发，负责查询当前活动排期、可用抽奖机会并执行抽奖，返回中奖权益或优惠券（如满减红包、外卖秒杀券、免单卡资格）。

* **API**: `mtop.alsc.upp.market.timelimitdraw.consultunit`
* **版本**: `1.0` (网关路径: `/1.0/2.0/`)
* **HTTP 方法**: `POST`
* **Content-Type**: `application/x-www-form-urlencoded`

#### 1) 请求参数 (URL 参数 `data` 或 POST Body `data=...`)
```json
{
```

### 1.3 权益中心与免单规则接口 (`rights.page.recall`)

* **API**: `mtop.ele.rights.page.recall`
* **版本**: `1.0`
* **HTTP 方法**: `GET`
* **场景标识**: `sceneCode: "ENGAGE_HUB"` 或 `"ET_RIGHTS_CENTER"`
* **提取出的免单业务规则与配置** (`tb.log` 第 1119 行):
  1. **参与门槛与上限**:
     * `"guideTip": "订单实付满7元且送达可参与，最高得100元免单卡，每天最高免3单；详见右上角规则"`
     * `"mainTitle": "本页面下单可赢免单卡，下多少免多少"`
     * `"winningText": "其中{orderAmountYuan}的订单已中免单卡"`
  2. **中奖与开奖延迟**:
     * `"orderFreeDrawDelaySeconds": 1`: 订单满足条件后延迟 1 秒可触发免单卡抽取。
  3. **关联场景代码**:
     * `sceneCodes`: `[{"value": "ETMD"}, {"value": "EMD"}, {"value": "interact_center"}, {"value": "SECKILL"}]` (饿了么淘宝免单 / 饿了么免单)
  4. **签到主按钮配置 (`mainButtonConfig.data`)**:
     * `unsignedSingle`: `"领取签到奖励"`
     * `signedTaskList`: `"领幸运星兑免单"`
     * `unsignedDoubleStars`: `"领取签到奖励"`
     * **签到状态判定**: 当用户今日未签到时，主按钮文案为 `unsignedSingle`（领取签到奖励）；已签到后，主按钮引导进入任务列表 `signedTaskList`（领幸运星兑免单）。

## 二、免单任务执行策略与状态处理

### 2.1 签到流程
1. 调用 `mtop.ele.rights.page.recall(sceneCode="ENGAGE_HUB")` 检查签到状态。
2. 若 `mainButtonConfig.data.unsignedSingle == "领取签到奖励"`，触发签到领奖。
3. 签到成功后置本地 Flag（`hasFlagToday("elemeFreeOrderSign")`），避免重复调用。

### 2.2 抽免单流程
1. 调用 `mtop.alsc.upp.market.timelimitdraw.consultunit` 传入当前坐标与排期 ID。
2. 提取响应中的 `rightSendDTOS`，记录中奖券信息与外卖秒杀券。
3. 调用 `mtop.alsc.upp.tbet.send` 领取免费爆红包资产。

### 2.3 联动任务闭环
1. 在拉取幸运星任务列表时，识别 `missionDefId == 47202001`（抽惊喜免单）。
2. 该任务要求进入免单插件首页，通过模拟页面浏览完成该任务。
3. 完成后立即调用 `receivePrize(47202001, missionXId)` 领取 80 幸运星。

### 3.1 RPC 封装层示例 (`FreeOrderRpcCall.kt`)
```kotlin
package fansirsqi.xposed.sesame.task.otherTask2.eleme

import fansirsqi.xposed.sesame.hook.MtopSender
import fansirsqi.xposed.sesame.hook.internal.LocationHelper
import org.json.JSONArray
import org.json.JSONObject

object FreeOrderRpcCall {
    private const val BIZ_CODE = "TIME_LIMIT_DRAW_NEW"
    private const val MARKET_TYPE = "TIME_LIMIT_DRAW"
    private const val ENCRYPT_SCENE_CODE = "71cclR57CFNhphC9bF4eTA=="
    private const val DEFAULT_SCHEDULE_ID = "2607298507304601043"

    /**
     * 限时抽免单咨询与抽奖
     */
    fun consultDraw(scheduleId: String = DEFAULT_SCHEDULE_ID): MtopSender.Result {
        val data = JSONObject().apply {
            put("bizCode", BIZ_CODE)
            put("marketType", MARKET_TYPE)
            put("encryptSceneCode", ENCRYPT_SCENE_CODE)
            put("scheduleIds", JSONArray().put(scheduleId).toString())
            put("spPageId", "26090924198822617")
            put("instance", "INNER")
            LocationHelper.getLocation()?.let {
                put("latitude", it.optDouble("latitude", 25.274215))
                put("longitude", it.optDouble("longitude", 110.299121))
            }
        }
        return MtopSender.send("mtop.alsc.upp.market.timelimitdraw.consultunit", "1.0", data.toString(), true, null)
    }

    /**
     * 自动发放爆红包资产
     */
    fun sendTbetCoupon(): MtopSender.Result {
        val extObj = JSONObject().apply {
            put("subSubChannel", "miniapp.alipay.et")
            put("popup_source_from", "APP_READY")
            put("tbet_no_login", "false")
            put("tbsid", "")
        }
        val data = JSONObject().apply {
            put("ext", extObj.toString())
            put("instance", "INNER")
        }
        return MtopSender.send("mtop.alsc.upp.tbet.send", "1.0", data.toString(), false, null)
    }

    /**
     * 查询权益主页与免单规则
     */
    fun queryRightsPage(): MtopSender.Result {
        val data = JSONObject().apply {
            put("sceneCode", "ENGAGE_HUB")
            put("screenNum", "1")
            put("instance", "INNER")
            LocationHelper.getLocation()?.let {
                val locDto = JSONObject().apply {
                    put("latitude", it.optString("latitude", "25.274027"))
                    put("longitude", it.optString("longitude", "110.299078"))
                }
                put("locationDTO", locDto.toString())
            }
        }
        return MtopSender.send("mtop.ele.rights.page.recall", "1.0", data.toString(), false, null)
    }
}
```

### 3.2 业务调度器核心逻辑示例 (`FreeOrderTask.kt`)
```kotlin
package fansirsqi.xposed.sesame.task.otherTask2.eleme

import fansirsqi.xposed.sesame.data.Status
import fansirsqi.xposed.sesame.util.Log
import kotlinx.coroutines.delay

object FreeOrderTask {
    private const val TAG = "🎟️饿了么抽免单"

    suspend fun execute() {
        Log.other(TAG, "开始执行免单模块业务流...")

        // 1. 检查今日是否已执行签到与抽奖
        val signFlag = "eleme_free_order_sign"
        if (!Status.hasFlagToday(signFlag)) {
            val rightsRes = FreeOrderRpcCall.queryRightsPage()
            if (rightsRes.ok) {
                Log.other(TAG, "已查询权益中心与免单配置")
            }
            Status.setFlagToday(signFlag)
        }

        // 2. 领取爆红包 / 试用免单资产
        val tbetFlag = "eleme_tbet_coupon"
        if (!Status.hasFlagToday(tbetFlag)) {
            val tbetRes = FreeOrderRpcCall.sendTbetCoupon()
            if (tbetRes.ok) {
                val resultObj = tbetRes.body()?.optJSONObject("resultObj")
                val couponSend = resultObj?.optJSONObject("eatPluginResult")?.optJSONObject("EAT_PAID_COUPON_SEND")
                val rightName = couponSend?.optString("rightName", "爆红包")
                val count = couponSend?.optString("count", "0")
                Log.other(TAG, "🎉 成功领取 $count 张 [$rightName] 免单资产")
                Status.setFlagToday(tbetFlag)
            }
        }

        // 3. 执行限时抽免单 / 抽券
        delay(1000L)
        val drawRes = FreeOrderRpcCall.consultDraw()
        if (drawRes.ok) {
            val schedList = drawRes.body()?.optJSONObject("result")?.optJSONArray("scheduleInfoList")
            if (schedList != null && schedList.length() > 0) {
                val rights = schedList.optJSONObject(0)?.optJSONArray("rightSendDTOS")
                if (rights != null && rights.length() > 0) {
                    val discount = rights.optJSONObject(0)?.optJSONObject("discountInfo")
                    val reduction = discount?.optString("reductionYuan", "0")
                    val threshold = discount?.optString("thresholdYuan", "0")
                    Log.other(TAG, "🎯 抽免单/抽奖成功，获得满 $threshold 减 $reduction 元外卖券！")
                } else {
                    Log.other(TAG, "已触发限时抽免单咨询，无新增权益下发")
                }
            }
        } else {
            Log.error(TAG, "限时抽免单失败: ${drawRes.retMsg}")
        }
    }
}
```
