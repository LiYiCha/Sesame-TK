# 支付宝主题替换完整方案

## 问题分析

### 之前方案失败的原因

1. **MD5随便填** → 触发SCInnerManager的MD5校验，导致重新下载
2. **只修改SharedPreferences** → 内存缓存（`this.g`和`this.h`）未更新
3. **缓存时间过期** → `SCConfigUtil.m()`检查失败
4. **没有Hook验证逻辑** → 无法绕过支付宝的多重检查

### 核心问题

支付宝的主题系统有**三层验证**：
- **持久化层**：SharedPreferences存储
- **内存层**：Map缓存（需要重启才能重新加载）
- **验证层**：MD5、时间戳、用户ID等多重校验

## 完整解决方案

### 方案架构

```
┌─────────────────────────────────────────────────────────┐
│                    Xposed Hook 层                        │
├─────────────────────────────────────────────────────────┤
│  1. Hook缓存读取   → 注入自定义主题信息到内存          │
│  2. Hook MD5校验   → 绕过MD5验证                        │
│  3. Hook时间戳检查 → 防止缓存过期                       │
│  4. Hook启用检查   → 强制启用主题                       │
│  5. Hook文件路径   → 指向自定义主题目录                 │
│  6. Hook资源加载   → 确保加载自定义资源                 │
├─────────────────────────────────────────────────────────┤
│                   文件替换层                             │
├─────────────────────────────────────────────────────────┤
│  ThemeManager.kt  → 替换主题资源文件                    │
└─────────────────────────────────────────────────────────┘
```

## 实现步骤

### 第一步：集成ThemeHook到项目

在你的Hook入口类中添加：

```kotlin
// 在ApplicationHook.java或主Hook类中

import fansirsqi.xposed.sesame.hook.theme.ThemeHook

class YourMainHook : IXposedHookLoadPackage {
    override fun handleLoadPackage(lpparam: XC_LoadPackage.LoadPackageParam) {
        if (lpparam.packageName != "com.eg.android.AlipayGphone") {
            return
        }

        // 初始化ThemeHook
        ThemeHook.setupHooks(lpparam.classLoader)

        // 在适当的时机应用Hook（例如Application.onCreate之后）
        // 建议在配置加载完成后调用
        ThemeHook.applyHooks(true)  // true表示启用
    }
}
```

## Hook点详解

### Hook 1: 缓存读取（最关键）

**位置**: `SCInnerManager.K()` (readSkinInfoFromLocalCache)

**作用**: 在支付宝读取缓存后，立即注入自定义主题信息到内存缓存

**关键代码**:
```kotlin
// 获取内存缓存Map
val cacheMap = XposedHelpers.getObjectField(manager, "g")

// 创建自定义缓存信息
val customCache = cacheInfoClass.newInstance()
XposedHelpers.setObjectField(customCache, "usageScene", "theme")
XposedHelpers.setObjectField(customCache, "skinId", CUSTOM_SKIN_ID)
XposedHelpers.setObjectField(customCache, "md5", CUSTOM_MD5)

// 设置缓存时间为未来时间（100年后）
val futureTime = System.currentTimeMillis() + (100L * 365 * 24 * 60 * 60 * 1000)
XposedHelpers.setLongField(customCache, "cacheTime", futureTime)

// 注入到内存缓存
cacheMap["theme"] = customCache
```

**为什么重要**:
- 解决了"需要重启才能看到主题"的问题
- 直接修改内存缓存，无需重启
- 设置未来时间戳，防止过期

### Hook 2: MD5校验

**位置**: `SCConfigUtil.m()`

**作用**: 绕过MD5和时间戳检查

**关键代码**:
```kotlin
XposedHelpers.findAndHookMethod(
    "com.alipay.mobile.skincenter.util.SCConfigUtil",
    classLoader,
    "m",
    String::class.java,
    Long::class.javaPrimitiveType,
    object : XC_MethodReplacement() {
        override fun replaceHookedMethod(param: MethodHookParam): Any {
            return false  // 返回false表示不过期
        }
    }
)
```

**为什么重要**:
- 解决了"MD5随便填导致重新下载"的问题
- 防止支付宝检测到MD5不匹配而重新下载主题

### Hook 3: 时间戳检查

**位置**: `SCConfigUtil.l()` (isThemeSkinRollBack)

**作用**: 防止主题被回滚

**关键代码**:
```kotlin
XposedHelpers.findAndHookMethod(
    "com.alipay.mobile.skincenter.util.SCConfigUtil",
    classLoader,
    "l",
    object : XC_MethodReplacement() {
        override fun replaceHookedMethod(param: MethodHookParam): Any {
            return false  // 返回false表示不回滚
        }
    }
)
```

### Hook 4: hasEnableSkin检查

**位置**: `SCInnerManager.y()`

**作用**: 强制启用主题

**关键代码**:
```kotlin
XposedHelpers.findAndHookMethod(
    scInnerManagerClass,
    "y",
    String::class.java,
    Map::class.java,
    object : XC_MethodHook() {
        override fun beforeHookedMethod(param: MethodHookParam) {
            val scene = param.args[0] as? String
            if (scene == "theme") {
                param.result = true  // 强制返回true
            }
        }
    }
)
```

**为什么重要**:
- 解决了"主题只能显示一段时间"的问题
- 绕过支付宝的启用检查逻辑

### Hook 5: 文件路径

**位置**: `SCInnerManager.q()`

**作用**: 确保指向正确的自定义主题目录

**关键代码**:
```kotlin
XposedHelpers.findAndHookMethod(
    scInnerManagerClass,
    "q",
    File::class.java,
    String::class.java,
    String::class.java,
    object : XC_MethodHook() {
        override fun afterHookedMethod(param: MethodHookParam) {
            val scene = param.args[1] as? String
            if (scene == "theme") {
                val baseDir = param.args[0] as? File
                val customThemeDir = File(baseDir, "theme/$CUSTOM_USER_SKIN_ID")
                param.result = customThemeDir
            }
        }
    }
)
```

### Hook 6: 资源加载

**位置**: `SCMetaModel.loadResSync()`

**作用**: 确保从自定义主题目录加载资源

**关键代码**:
```kotlin
XposedHelpers.findAndHookMethod(
    scMetaModelClass,
    "loadResSync",
    String::class.java,
    Map::class.java,
    Boolean::class.javaPrimitiveType,
    Boolean::class.javaPrimitiveType,
    String::class.java,
    object : XC_MethodHook() {
        override fun beforeHookedMethod(param: MethodHookParam) {
            val metaModel = param.thisObject
            val scene = XposedHelpers.getObjectField(metaModel, "scene")
            if (scene == "theme") {
                XposedHelpers.setObjectField(metaModel, "skinId", CUSTOM_SKIN_ID)
                XposedHelpers.setObjectField(metaModel, "userSkinId", CUSTOM_USER_SKIN_ID)
            }
        }
    }
)
```

## 常见问题

### Q1: 主题还是只能显示一段时间？

**A**: 检查以下几点：
1. ThemeHook是否正确应用（查看日志）
2. MD5校验Hook是否生效
3. 时间戳检查Hook是否生效

### Q2: 需要重启支付宝才能看到主题？

**A**: 这是正常的，因为：
1. 缓存读取Hook在应用启动时执行
2. 第一次需要重启让Hook生效
3. 之后修改主题无需重启（如果使用ThemeManager的notifySkinChanged）

### Q3: 主题文件放在哪里？

**A**: 两个位置都可以：
1. **支付宝内部**（推荐）：
   `/data/data/com.eg.android.AlipayGphone/files/skin_center_dir/{用户ID}/theme/20260206003520010000120077249371/`

2. **SD卡**（配合ThemeManager）：
   `/storage/emulated/0/Android/media/com.eg.android.AlipayGphone/000_HOHO_THEME_CENTER/themes/my_theme/`

### Q4: 如何制作自定义主题？

**A**:
1. 先导出现有主题（使用ThemeManager的导出功能）
2. 修改导出的资源文件（图片、颜色等）
3. 修改meta.json配置
4. 使用ThemeManager导入

### Q5: 支持暗黑模式吗？

**A**: 支持！在meta.json中配置：
```json
{
  "image": "home_navi_bg",
  "dark#image": "dark#home_navi_bg",
  "position": "home_navi_bg",
  "type": "image"
}
```

## 技术原理

### 支付宝主题系统架构

```
┌─────────────────────────────────────────┐
│         SCInnerManager                   │  ← 主题管理核心
├─────────────────────────────────────────┤
│  - readSkinInfoFromLocalCache()  (K)    │  ← Hook点1: 缓存读取
│  - hasEnableSkin()               (y)    │  ← Hook点4: 启用检查
│  - getMetaModel()                (o)    │  ← 获取元数据
│  - getThemeFilePath()            (q)    │  ← Hook点5: 文件路径
│  - loadResource()                (D)    │  ← 资源加载
└─────────────────────────────────────────┘
           ↓
┌─────────────────────────────────────────┐
│         SCConfigUtil                     │  ← 配置工具类
├─────────────────────────────────────────┤
│  - checkMd5AndTime()             (m)    │  ← Hook点2: MD5校验
│  - isThemeSkinRollBack()         (l)    │  ← Hook点3: 回滚检查
└─────────────────────────────────────────┘
           ↓
┌─────────────────────────────────────────┐
│         SCMetaModel                      │  ← 元数据模型
├─────────────────────────────────────────┤
│  - loadResSync()                         │  ← Hook点6: 资源加载
│  - hasEnableSkin()                       │  ← 启用检查
└─────────────────────────────────────────┘
```

### Hook时机

```
应用启动
    ↓
Application.onCreate
    ↓
ThemeHook.setupHooks()  ← 初始化Hook
    ↓
ThemeHook.applyHooks()  ← 应用所有Hook
    ↓
SCInnerManager.K()      ← 读取缓存（Hook点1触发）
    ↓
注入自定义主题信息到内存
    ↓
SCInnerManager.y()      ← 检查是否启用（Hook点4触发）
    ↓
强制返回true
    ↓
SCMetaModel.loadResSync() ← 加载资源（Hook点6触发）
    ↓
显示自定义主题
```
