# 主题替换功能测试指南

## 实现概述

本次实现了**完整的主题替换功能**，模拟支付宝内部切换主题的流程，实现**无需重启立即生效**。

### 核心改进

1. **完整的主题切换流程**（ThemeManager.kt）
   - 删除旧的自定义主题
   - 导入新主题文件
   - 更新 SharedPreferences（指向新主题）
   - 清除内存缓存
   - 重新读取缓存
   - 刷新 UI

2. **改进的主题选择逻辑**（ThemeHookV2.kt）
   - 优先选择有 theme_info.json 的主题（自定义主题）
   - 如果有多个自定义主题，选择最新的
   - 避免随机选择官方主题

3. **双重保障机制**
   - 数据层面：SharedPreferences 和内存缓存正确
   - Hook 层面：6 个 Hook 作为保险，确保主题一定生效

## 完整流程

```
用户在 UI 中选择主题 → 点击"更新"
    ↓
ThemeManager.executeUpdateOperation()
    ├─ 1. 删除旧的自定义主题（有 theme_info.json 的主题）
    ├─ 2. 复制新主题文件到 /theme/{selectedThemeId}/
    ├─ 3. 读取并更新 theme_info.json（更新 userId 和 cacheTime）
    ├─ 4. 更新 SharedPreferences（指向新主题）
    ├─ 5. 清除内存缓存（清除 this.g 中的 "theme" 条目）
    ├─ 6. 重新读取缓存（调用 SCInnerManager.K() 方法）
    └─ 7. 刷新 UI（调用 AntSkinRenderManager.notifySkinChanged()）
    ↓
支付宝立即显示新主题（无需重启）
```

private fun executeUpdateOperation(userId: String, userThemeDir: File) {
    // 1. 删除旧的自定义主题

        file.isDirectory && File(file, "theme_info.json").exists()

    existingCustomThemes?.forEach { it.deleteRecursively() }

private fun clearMemoryCache() {

    val cacheMap = instance.g

}

### 2. ThemeHookV2.kt

#### loadThemeInfo() - 改进的主题选择逻辑
```kotlin
private fun loadThemeInfo(userId: String): ThemeInfo? {
    // 查找所有主题目录
    val themeDirs = themeBaseDir.listFiles { it.isDirectory }

    // 优先查找有 theme_info.json 的主题（自定义主题）
    val customThemes = themeDirs.filter { File(it, "theme_info.json").exists() }

    val themeDir = if (customThemes.isNotEmpty()) {
        // 如果有多个自定义主题，取最新的（按修改时间排序）
        customThemes.maxByOrNull { it.lastModified() }!!
    } else {
        // 如果没有自定义主题，取第一个（可能是官方主题）
        themeDirs[0]
    }

    // 读取 theme_info.json
    return JsonUtil.parseObject(themeInfoFile.readText(), ThemeInfo::class.java)
}
```

#### 6 个 Hook（保持不变，作为保险）

1. **hookCacheRead()** - 注入缓存信息
2. **hookMd5Check()** - 绕过 MD5 校验
3. **hookTimeCheck()** - 绕过时间戳检查
4. **hookHasEnableSkin()** - 强制启用主题
5. **hookFilePath()** - 修改文件路径
6. **hookResourceLoad()** - 修改资源加载

## 故障排查

### 问题 1：UI 没有改变

**可能原因**：
- SharedPreferences 更新失败
- 内存缓存清除失败
- notifySkinChanged() 调用失败

**解决方法**：
1. 查看日志，确认每个步骤是否成功
2. 如果某个步骤失败，检查错误信息
3. 尝试重启支付宝

### 问题 2：主题只显示一段时间

**可能原因**：
- MD5 校验失败
- 时间戳检查失败
- Hook 没有正确应用

**解决方法**：
1. 确认 Hook 是否成功应用（查看 ThemeHookV2 日志）
2. 确认 theme_info.json 中的 MD5 是真实的
3. 确认 expireDate 是很久以后的日期

### 问题 3：主题文件不存在

**可能原因**：
- 主题文件复制失败
- 主题目录被删除

**解决方法**：
1. 检查主题文件是否存在：
   ```bash
   adb shell "ls -la /data/data/com.eg.android.AlipayGphone/files/skin_center_dir/*/theme/"
   ```
2. 检查 theme_info.json 是否存在
3. 重新导入主题

### 问题 4：Hook 没有生效

**可能原因**：
- LSPosed 没有激活模块
- 配置中没有启用皮肤模块
- 支付宝版本不兼容

**解决方法**：
1. 确认 LSPosed 中已激活模块
2. 确认配置中启用了皮肤模块
3. 查看日志确认 Hook 是否成功

## 技术细节

### SharedPreferences 数据结构

```json
{
  "theme": {
    "usageScene": "theme",
    "skinId": "SKINC202600221903",
    "userSkinId": "my_custom_theme",
    "userId": "2088232515543121",
    "md5": "b7fc5bcf630301f07b79e830d74b8a63",
    "appSquareMd5": "b7fc5bcf630301f07b79e830d74b8a63",
    "cacheTime": 1770558529,
    "versionLimit": "10.8.20.0000",
    "isDiySkin": false,
    "name": "我的自定义主题",
    "expireDate": "2126-02-10",
    "skinType": "INST_UNLIMITED",
    "materialId": "",
    "diyExpiredTime": 0
  }
}
```

### 关键字段说明

- **userSkinId**: 决定使用哪个主题（主题目录名）
- **md5**: 主题文件的真实 MD5
- **cacheTime**: 缓存时间（秒）
- **expireDate**: 过期日期（100年后）

### Hook 触发时机

1. **hookCacheRead()**: 当 SCInnerManager.K() 被调用时（读取缓存）
2. **hookMd5Check()**: 当支付宝校验 MD5 时
3. **hookTimeCheck()**: 当支付宝检查时间戳时
4. **hookHasEnableSkin()**: 当支付宝检查是否启用主题时
5. **hookFilePath()**: 当支付宝获取主题文件路径时
6. **hookResourceLoad()**: 当支付宝加载主题资源时
